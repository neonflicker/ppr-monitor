# Security Policy

## Supported versions

Security fixes are applied to the current maintained version. There is no formal version support schedule at this time.

## Reporting a vulnerability

Please do not publish passwords, access tokens, private keys, personal data or exploitable vulnerability details in a public issue.

Contact the repository maintainer privately through:
https://github.com/neonflicker

Include a concise description, affected component, impact and steps to reproduce where safe.

## Credential exposure

If a secret is committed accidentally, revoke or rotate it immediately. Removing a file from the latest commit is not sufficient because the value may remain in Git history, forks, caches or downloaded archives.
