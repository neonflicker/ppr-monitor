# Contributing

Thank you for considering a contribution.

## Before opening an issue

- Search existing issues to avoid duplicates.
- Describe the affected feature and expected behaviour.
- Remove personal information, production records, credentials and private URLs from screenshots and logs.
- Use synthetic or anonymised data when describing import or reporting problems.

## Pull requests

1. Fork the repository and create a focused branch.
2. Keep changes limited to one bug fix or feature where practical.
3. Follow the existing TypeScript, React and Convex patterns.
4. Never commit environment files, credentials or real operational datasets.
5. Run relevant checks:

   ```bash
   npm run build
   npm run lint
   ```

6. Explain the change and how it was tested.

## Data and privacy

Do not submit identifiable farmer, livestock-owner, employee or other personal data. Do not include production database exports or private departmental documents in issues or pull requests.

## Review

Contributions may be reviewed for correctness, security, privacy, maintainability and compatibility.
